# NutcrackerSnowglobe Stage 8-9

Цель: добавить этапы 8-9: мыши на шаре и бой снежками.

Как запустить:
- Откройте проект в Unity 6000.0.29f1.
- Откройте сцену SnowballLevel.
- Нажмите Nutcracker -> Apply Stage 8 (mice) для размещения мышей вокруг планеты.
- Нажмите Nutcracker -> Apply Stage 9 (авторская) если хотите добавить логику урона и столкновений (сейчас базовая: мыши наносят урон игроку через OnCollisionEnter).
- Нажмите Play и проверьте, что мыши движутся по орбите, можно по ним попасть снежком, и игрок получает урон.

Файлы в архиве:
- Assets/Scripts/MouseEnemy.cs
- Assets/Scripts/SnowballProjectile.cs
- Assets/Editor/Stage8SceneTool.cs
- Assets/Editor/Stage9SceneTool.cs (опционально, если будет добавлена)
